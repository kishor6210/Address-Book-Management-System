# Address Book

A console-based Address Book application developed in C for managing contacts.

## Features

- Add Contact
- Search Contact
- Edit Contact
- Delete Contact
- Display Contacts
- Save and Load Contacts
- Input Validation
- Menu-Driven Interface

## Technologies Used

- C Programming
- Structures
- Arrays of Structures
- String Handling
- File Handling
- Functions

## How to Compile

```bash
gcc *.c
```

## How to Run

```bash
./a.out
```

- CRUD Operations
